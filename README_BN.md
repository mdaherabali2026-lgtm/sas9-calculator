# SAS9 1654X — PWA Ready

এই ফোল্ডারটি আপনার HTML calculator-কে PWA হিসেবে ব্যবহার করার জন্য প্রস্তুত করা হয়েছে।

ফাইল:
- `index.html` — আপনার calculator
- `manifest.webmanifest` — app name/icon/display settings
- `sw.js` — offline cache/service worker
- `icons/` — 192px ও 512px app icons

## মোবাইল থেকে পরের ধাপ
1. পুরো `SAS9_1654X_PWA` folder-এর ফাইলগুলো HTTPS hosting-এ upload করুন।
2. `index.html` যে URL-এ খুলে, সেই URL Chrome-এ পরীক্ষা করুন।
3. PWABuilder-এ URL দিন এবং Android package তৈরি করুন।
4. Play Store-এর জন্য AAB package ব্যবহার করুন।

নোট: AdMob/বিজ্ঞাপনের কোনো code এখানে যোগ করা হয়নি।
